# FENIX ONLINE — единый Telegram-бот

## Функции
- Регистрация по игровому нику и отдельному паролю (хранится PBKDF2-хеш).
- Личный кабинет, реферальная ссылка, статистика и рейтинг.
- Учёт регистраций по ссылке бота.
- Персональные ссылки `/invite` на вступление в Telegram-канал с учётом вступлений.
- Заявки в медиапартнёры с одобрением/отклонением владельцем.
- Панель владельца: публикация постов с фото и inline-кнопкой, рассылка, статистика.
- Настройка подписи и URL кнопки главного меню.
- SQLite база на постоянном диске Render.

## Важные условия
- Чтобы считать реальные вступления в канал, добавь бота администратором канала и дай право приглашать пользователей/управлять ссылками. Участники должны вступать по персональным ссылкам, которые бот выдаёт командой `/invite`.
- Реферальная ссылка `t.me/бот?start=rID` учитывает отдельно тех, кто зарегистрировался в боте. Эти цифры не смешиваются с вступлениями в канал.
- Автоматическое начисление доната пока не включено: бот считает результаты, владелец проверяет и выдаёт награду вручную.
- Пароль — дополнительный пароль кабинета, не пароль Telegram.
- Добавь бота в канал администратором с правом публикации сообщений.
- Для владельца: запусти бота, отправь `/id`, затем внеси свой ID в `ADMIN_IDS` и перезапусти.
- Для одного процесса используется SQLite. На Render необходим Persistent Disk.

## Windows: локальный запуск
1. Установи Python 3.11/3.12.
2. Распакуй архив и открой PowerShell в папке проекта.
3. Выполни:
   ```powershell
   py -3.12 -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   Copy-Item .env.example .env
   notepad .env
   python bot.py
   ```

## GitHub + Render
1. Создай репозиторий GitHub и загрузи содержимое архива без `.env`.
2. На Render выбери New → Blueprint и подключи репозиторий с `render.yaml`.
3. В Environment добавь BOT_TOKEN, ADMIN_IDS, CHANNEL_ID, CHANNEL_URL.
4. Разверни сервис. Это должен быть Worker, не Web Service. Persistent Disk и постоянно работающий Worker могут требовать платный тариф Render — проверь актуальные условия тарифа перед запуском.
5. Не публикуй токен и не загружай `.env` в GitHub.

## Первая настройка
- `@BotFather` → создать бота → получить BOT_TOKEN.
- Добавить бота администратором Telegram-канала.
- Указать `CHANNEL_ID` как `@username` публичного канала или `-100...` для приватного.
- Запустить бота и узнать Telegram ID командой `/id`.
