# FENIX ONLINE — единая инструкция

Это руководство описывает текущие функции FENIX ONLINE и FENIX MANAGER. В Telegram-боте актуальная версия Telegraph открывается командами `/help` и `/commands`. В группах краткая справка вызывается через `!help`; в ней есть кнопка перехода к полной статье.

## 1. Как пользоваться

- Личные команды Telegram-бота начинаются с `/`.
- Команды FENIX MANAGER выполняются в группах и обычно начинаются с `!`.
- Если команда требует участника, надёжнее ответить на его сообщение. Альтернативно можно указать числовой Telegram ID.
- Возможности зависят от регистрации, уровня роли, индивидуальных настроек доступа и разрешений бота в Telegram.
- Не публикуйте пароли, токены, коды входа и платёжные данные.

## 2. Личный бот и кабинет

| Команда | Назначение |
|---|---|
| `/start` | Главное меню, проверка обязательной подписки и регистрация/вход |
| `/help`, `/commands` | Единая полная инструкция FENIX |
| `/cancel` | Отменить текущий пошаговый ввод |
| `/id` | Показать Telegram ID |
| `/fenixid`, `/idcard` | Карточка FENIX ID |
| `/invite` | Реферальная ссылка и раздел приглашений |
| `/media_video` | Передать сведения о видео/публикации в медиа-раздел |
| `/gifts` | Открыть магазин Telegram-подарков FENIX |
| `/promo КОД` | Активировать промокод на следующий заказ подарка |

В зависимости от статуса аккаунта личный кабинет содержит профиль, статистику, достижения, уведомления, поддержку и обращения. Переписка по обращениям сохраняется. Ответ администрации отображается в уведомлениях/разделе обращений.

## 3. FENIX MEDIA

Медиа-раздел может включать сведения о канале, статистику видео, календарь, историю публикаций и выплат. `/media_video` отправляет ссылку и сведения о публикации для проверки. Статусы выплаты: на проверке, выплачено или отклонено. Отправка заявки не означает автоматическое подтверждение выплаты.

## 4. Магазин и платежи

Mini App содержит магазин FENIX, кошелёк NMZ, заказы и профиль. Каталог, цены и курс настраиваются владельцем. Ручной платёж учитывается после подтверждения администрацией. Создание заказа само по себе не означает автоматическую выдачу предмета на игровой сервер: для этого требуется отдельное серверное API или доступ к игровой базе данных.

## 5. Состав и служебные чаты

- `/staffhelp` — инструкция управления составом.
- `/chatid` — ID текущего чата/пользователя и служебные привязки (для администрации бота).
- `/bind_admin_chat` — привязать текущую группу как административный чат.
- `/bind_leader_chat` — привязать текущую группу как лидерский чат.
- `/stafflist` — список состава текущего привязанного чата.
- `/nnick ИГРОВОЙ_НИК ДОЛЖНОСТЬ` — назначить или изменить должность.
- `/staffremove ИГРОВОЙ_НИК` — снять должность.
- `/setlabel КЛЮЧ НАЗВАНИЕ` — изменить подпись кнопки меню (cab, ref, stats, top, media; только владелец).
- `/chatmanager` — панель подключённых бесед (владелец/администратор бота).

Привязку выполняет администратор бота непосредственно внутри нужной группы.

## 6. Premium Custom Emoji (владелец бота)

- `/emojipack` — импортировать Telegram-набор Custom Emoji.
- `/emojipacks` — список импортированных наборов.
- `/emojipackremove` — удалить набор.
- `/emojilist` — список сохранённых emoji ID.
- `/emojistatus` — состояние набора.
- `/btnlist` — каталог кнопок и ключи.
- `/setbtnemoji НОМЕР_КНОПКИ НОМЕР_ЭМОДЗИ` — назначить значок по номерам.
- `/setbtnemojiid КЛЮЧ ID_ЭМОДЗИ` — назначить значок по ключу и custom_emoji_id.
- `/resetbtnemoji` — сбросить индивидуальные назначения.
- `/clearbuttonemoji` — очистить назначения.
- `/premiumall`, `/premiumstop` — начать/остановить пошаговую настройку.
- `/setbtnstyle НОМЕР primary|success|danger|default` — стиль поддерживаемой кнопки.

Наличие импортированного ID не гарантирует отображение Premium Emoji: Telegram проверяет права владельца бота.

## 7. Подключение FENIX MANAGER к группе

1. Добавьте `@FenixMediarobot` в группу.
2. Назначьте бота администратором.
3. Выдайте необходимые права: удаление сообщений, блокировка/ограничение участников, закрепление сообщений и управление приглашениями.
4. От имени владельца группы выполните `!setup`.
5. Проверьте настройки командой `!settings`.

Владелец группы получает уровень 100, если Telegram сообщает боту статус creator. Панель владельца бота открывается командой `/chatmanager` в личном чате.

## 8. Роли

| Уровень | Роль |
|---:|---|
| 0 | Участник |
| 20 | Помощник |
| 40 | Модератор |
| 60 | Администратор |
| 80 | Главный администратор |
| 100 | Владелец |

Уровень проверяется отдельно для каждой команды. Также могут применяться индивидуальные ограничения доступа.

## 10. Модерация

- `!mute 15m ПРИЧИНА` — ограничить участника; форматы срока: `30s`, `15m`, `2h`, `3d`.
- `!unmute` — снять ограничение.
- `!kick` — исключить участника.
- `!warn ПРИЧИНА` — выдать предупреждение; `!unwarn ID` — снять.
- `!getwarn ID`, `!warnhistory ID`, `!warnlist` — предупреждения и история.
- `!ban [ДНИ] ПРИЧИНА`, `!unban ID`, `!getban ID`, `!banlist` — блокировки.
- `!del` — удалить сообщение (ответом на него).
- `!purge КОЛИЧЕСТВО` — удалить последние сообщения (до 100).

Базовые действия модерации доступны помощнику (20+) при наличии соответствующих прав Telegram.

## 11. Игровые ники и управление ролями

- `!getnick ID`, `!nick`, `!gnick` — посмотреть игровой ник.
- `!setnick ID НИК` — сохранить внутренний игровой ник.
- `!removenick ID` — удалить ник.
- `!nicknames` — список; `!nonames` — записи без ника; `!getbynick НИК` — поиск.
- `!addhelper ID` — назначить помощника (40+).
- `!addmoder ID` — назначить модератора (60+).
- `!addadmin ID` — назначить администратора (80+).
- `!setrole ID 20|40|60|80|100`, `!removerole ID` — управление ролями (80+).
- `!newrole УРОВЕНЬ НАЗВАНИЕ`, `!deleterole УРОВЕНЬ` — название роли/удаление назначений уровня.
- `!wipe warns|filters|logs|nicks` — очистка выбранных данных; используйте осторожно.

## 12. Настройки, фильтры и ссылки

- `!setup`, `!settings`, `!settingsmute`, `!settingsinvite` — настройка и просмотр режимов.
- `!setsettings mute on|off` — режим ограничений.
- `!setsettings invite on|off` — режим приглашений.
- `!welcome ТЕКСТ` — приветствие; `{name}` и `{id}` подставляют данные участника.
- `!setrules ТЕКСТ` — текст правил.
- `!silence` — режим тишины.
- `!filters`, `!filteradd ФРАЗА`, `!filterdel ФРАЗА` — фильтры (60+).
- `!addlink URL`, `!whitelistlinks` — белый список ссылок (60+).
- `!pin`, `!unpin` — закрепить/открепить сообщение ответом на него.

## 13. Автоматизация и инструменты

- `!antispam on|off|status` — антиспам (60+).
- `!triggeradd ФРАЗА => ОТВЕТ`, `!triggerdel ФРАЗА`, `!triggers` — автоответы (60+).
- `!access КОМАНДА 0|20|40|60|80|off` — уровень доступа или отключение команды (80+).
- `!logs` — журнал действий.
- `!zov` — подсказка по объявлению; Telegram не позволяет гарантированно упомянуть всех участников.

## 14. Заметки, закладки, напоминания и голосования

- `!note add ТЕКСТ` — заметка; ответом на сообщение — заметка для его автора.
- `!note list`, `!notes` — список; `!note del ID` — удалить.
- `!bookmark` — сохранить сообщение ответом; `!bookmarks` — список; `!unbookmark ID` — удалить.
- `!timer 10m ТЕКСТ` — напоминание от 10 секунд до 30 дней; `!timers` — список; `!timerdel ID` — отменить.
- `!vote ВОПРОС | ВАРИАНТ 1 | ВАРИАНТ 2` — опрос с 2–6 вариантами.
- `!voteresult ID` — результат; `!voteclose ID` — закрыть опрос.

## 16. Ограничения Telegram

Telegram Bot API не предоставляет боту полный список участников группы, их онлайн-статусы или дату создания Telegram-аккаунта. `!setnick` меняет внутренний ник FENIX MANAGER, а не имя Telegram. Для работы модерации нужны права администратора группы.

Команды `!voice`, `!mafia`, `!emoji` и `!enick` зарезервированы и в текущей версии не выполняют действий.
