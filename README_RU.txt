FENIX ONLINE — список администрации и поиск игроков

В архиве:
- bot.py — обновлённые команды сотрудников и поиска игроков;
- db.py — методы поиска игроков и чтения должностей;
- requirements.txt — зависимости проекта.

УСТАНОВКА
1. Сделай резервную копию текущих bot.py и db.py.
2. Замени в GitHub только bot.py и db.py файлами из этого архива.
3. Папку assets не удаляй и не заменяй — оставь текущую.
4. Проверь, что ADMIN_IDS содержит Telegram ID владельца.
5. Commit changes и дождись успешного Deploy на Render.
6. В назначенном админ-чате владелец один раз выполняет /setadminchat (если чат ещё не назначен).

КОМАНДЫ В АДМИН-ЧАТЕ
/nnick Fenix_Rudcov Спец. администратор
  Добавляет зарегистрированного игрока в таблицу состава и назначает должность.
  Повторный /nnick для того же ника обновляет должность.

/nick
  Показывает красивый список назначенных сотрудников. Игровые ники кликабельны и открывают Telegram-профиль.

/stafflist
  Показывает список состава в компактном виде.

ДРУГИЕ КОМАНДЫ ДЛЯ АДМИНОВ БОТА
/users — список зарегистрированных игроков (до 80 отображаются в сообщении).
/find часть_ника — поиск по игровому нику или Telegram username.
/userinfo Fenix_Rudcov — карточка игрока, Telegram ID, должность и наличие доступа к панели.

ВАЖНО ПРО ДОСТУП
/nnick меняет только таблицу назначенного состава админ-чата и должность. Эта команда НЕ выдаёт права на панель бота и не даёт право модерировать группу.
Чтобы выдать доступ к панели бота с подтверждением владельца, используй прежнюю процедуру /staff Ник Должность и кнопки «Дать доступ к боту» / «Отказать».

ССЫЛКИ НА ПРОФИЛИ
Кликабельная ссылка формируется по Telegram ID пользователя (tg://user?id=...). Поэтому целевой игрок должен быть зарегистрирован в боте, чтобы его можно было найти по игровому нику.

ПРОВЕРКА
Локально проверены компиляция Python и операции SQLite: поиск игрока, назначение/чтение должности и вывод списка. Действия нужно дополнительно проверить на работающем Telegram-боте после Deploy.
