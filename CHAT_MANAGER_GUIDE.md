# FENIX CHAT MANAGER

Система управления Telegram-группами внутри FENIX ONLINE. Настройки, роли и журналы хранятся отдельно для каждой беседы в общей PostgreSQL/SQLite базе проекта.

## Подключение

1. Добавьте @FenixMediarobot в группу.
2. Назначьте бота администратором и выдайте необходимые права: удаление сообщений, блокировка участников, ограничение участников, закрепление сообщений и управление приглашениями.
3. От имени владельца группы отправьте `!setup`.
4. Проверьте конфигурацию через `!settings`.
5. В личном чате с ботом владелец FENIX может открыть панель проекта → «Чат-менеджер» или отправить `/chatmanager`.

Бот фиксирует группу при добавлении в неё и при выполнении команд управления. Список групп доступен владельцам бота.

## Уровни доступа

| Роль | Приоритет |
|---|---:|
| Владелец | 100 |
| Главный администратор | 80 |
| Администратор | 60 |
| Модератор | 40 |
| Помощник | 20 |
| Участник | 0 |

Владелец группы автоматически получает 100-й уровень после первой команды в группе, если Telegram сообщает боту статус creator. Глобальные администраторы FENIX также могут управлять беседами.

## Основные команды

### Участники
- `!help`, `!cmds`, `!команды`, `!помощь` — справка.
- `!start`, `!начать` — запустить Chat Manager в группе.
- `!ping`, `!status`, `!статус` — состояние бота.
- `!rules`, `!правила` — правила беседы.
- `!try`, `!попытка` — развлекательный ответ.
- `!kiss`, `!поцелуй` и `!obnyat`, `!обнять` — действие над участником (ответом на его сообщение или числовым ID).
- `!report текст` — отправить обращение руководству.
- `!admins`, `!staff`, `!админы` — список назначенных руководителей.

### Помощник · 20
- `!stats [ID]` — профиль FENIX, роль и предупреждения.
- `!chatinfo` — сведения о беседе.
- `!mute [ID] [30s/15m/2h/3d] [причина]`, `!unmute [ID]` — ограничение и снятие ограничения.
- `!kick [ID] [причина]` — исключение.
- `!warn [ID] [причина]`, `!unwarn [ID]`, `!getwarn [ID]`, `!warnhistory [ID]`, `!warnlist` — предупреждения.
- `!getban [ID]` — проверить статус участника.
- `!getnick [ID]`, `!setnick [ID] [ник]`, `!removenick [ID]`, `!nicknames`, `!nonames`, `!getbynick [ник]` — внутренние ники Chat Manager.
- `!logs` — журнал модерации.
- `!zov текст` — справочная команда для объявления.

### Модератор · 40
- `!ban [ID] [дни] [причина]`, `!unban [ID]`, `!banlist`.
- `!addhelper [ID]`, `!setrole [ID] [20/40/60/80]`, `!removerole [ID]`, `!roles`.
- `!silence` — переключить режим тишины.
- `!wipe warns|filters|logs|nicks` — очистить выбранный список.

### Администратор · 60
- `!addmoder [ID]`, `!addadmin [ID]`.
- `!filters`, `!filteradd фраза`, `!filterdel фраза`, `!filteredit`.
- `!addlink https://...`, `!whitelistlinks`.

### Главный администратор · 80
- `!pin` — ответом на сообщение закрепить его; `!unpin` — открепить.
- `!newrole [приоритет] [название]`, `!deleterole [приоритет]`.
- `!welcome текст`, `!setrules текст`.

### Владелец · 100
- `!setup`, `!settings`, `!setsettings mute on|off`, `!setsettings invite on|off`.
- `!settingsmute`, `!settingsinvite`.
- `!unity`, `!unites`, `!addunity название`, `!removeunity`, `!editunity новое название`, `!deleteunity название`.

## Ограничения Telegram API

- `!online` и полный список участников: Bot API не предоставляет боту полный перечень участников и их online-статусы.
- `!reg`: Telegram не раскрывает дату создания аккаунта. Доступна только дата регистрации в базе FENIX, если пользователь там есть.
- `!setnick` меняет внутренний ник в базе Chat Manager, но не имя Telegram-профиля.
- `!zov` не может автоматически упомянуть абсолютно всех: у бота нет гарантированного доступа к полному списку участников.
- Голосовая генерация `!voice`, полноценная игра `!mafia`, а также изменение emoji-статуса Telegram `!emoji/!enick` требуют отдельных модулей/разрешений и в текущем релизе не включены.
- Команды с ID/ссылками: самый надёжный способ — ответить на сообщение участника или указать числовой Telegram ID. Username-ссылки не всегда позволяют боту получить ID пользователя.

## Premium Emoji

Bot API поддерживает `icon_custom_emoji_id` в inline- и reply-кнопках, но Telegram разрешает это только если владелец бота имеет активный Telegram Premium либо бот получил подходящие дополнительные usernames через Fragment. При отсутствии права Telegram не покажет кастомный значок; обычный emoji в подписи кнопки оставлен как fallback. Пак OutlineEmoji автоматически импортируется при запуске, но импорт ID сам по себе не выдаёт право их отображать.
